# Siddharth Jadhav Professional Portfolio

A professional and academic portfolio covering AI platform engineering and coursework in the Master of Science in Computer Information Systems with an AI specialization at Indiana Wesleyan University.

## Hosting

This repository contains the static website published through GitHub Pages. The publishing source is the root directory of the main branch. The .nojekyll file preserves the HTML, CSS, JavaScript and downloadable files without a Jekyll build.

## Contents

- index.html: professional bio, personal value proposition, experience and coursework collection
- app.js: artifact entries and pending-entry details
- style.css: shared website styling
- artifacts/changeguide.html: Artifact 1 case study with the required course sections
- artifacts/changeguide-case-study.md: downloadable audience-facing case study
- artifacts/ml-vs-deep-learning.html: Artifact 2 comparison with all required portfolio sections
- artifacts/ml-vs-deep-learning-guide.docx: downloadable audience-facing comparison guide
- artifacts/verifying-ai-answers.html: Artifact 3 portfolio write-up
- artifacts/verifying-ai-answers-guide.docx: standalone guide for verifying AI-generated claims
- artifacts/assets/: screenshot evidence
- Course-Artifact-Template.md: structure for future course artifacts

## Updating the portfolio

Edit the site files and push the changes to main. GitHub Pages republishes the website from that branch. Add completed course artifacts with their tangible deliverables and supporting information, update the coursework entry in app.js, and update the count in index.html.

Keep required Brightspace reflections outside this public repository. The original course submission documents and private reflections are not part of this website.
